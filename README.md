# Phosphor Demake

Неофициальный Android-лаунчер в терминальном CRT-стиле, вдохновлённый [Phosphor](https://phosphor.zanoski.com/). Нативный интерфейс на Kotlin / Android Canvas, настраиваемые страницы и офлайн-арт из [ascii.rest](https://ascii.rest/).

**[Скачать APK](https://github.com/Arkuda/phosphor_demake/releases/latest/download/app-debug.apk)** · [Все релизы](https://github.com/Arkuda/phosphor_demake/releases) · [История изменений](CHANGELOG.md)

**1.7.1:** обычное **«Лесное озеро»** возвращено строго из опубликованного **1.6.0**; промежуточный вариант, ошибочно попавший в 1.7, удалён. **«Лесное озеро true-ascii»** остаётся отдельным пунктом без изменений. Сохранённый выбор не переключается автоматически.

## Возможности

- Блочные часы с мигающим двоеточием, смещённой тенью и секундами. Усиленный CRT: скан-линии, фосфорная сетка, мягкая проходящая полоса, виньетка и стеклянная рамка; без резких вспышек. Эффект выключается через **CRT glass**; 14 цветовых тем.
- До 10 настраиваемых страниц: dashboard, избранное, погода, уведомления, системный монитор, Zen, art, календарь, медиа и инструменты.
- Три настраиваемых перехода между страницами: **CRT beam**, **terminal slide**, **Matrix scan**; **off · instant** переключает без анимации. Арт ascii.rest движется вместе со страницей; отключение системных анимаций учитывается.
- Переключатель **widget frames** убирает рамки виджетов и внешний CRT-контур, не отключая скан-линии и остальные эффекты.
- Список установленных приложений с иконками размером с текст, инерционной прокруткой, поиском с поддержкой опечаток и запуском приложений.
- Пять упорядоченных позиций нижнего бара: выбор приложения для каждой позиции, собственные подписи, пустые позиции, перестановка без дубликатов и сохранение настроек.
- Отдельная страница **favorites**: выбранные приложения сохраняются независимо от нижнего бара; быстрый запуск, поиск, инерционная прокрутка и добавление/удаление через долгое нажатие.
- Диалоги с выделенными заголовками, разделителями и высотой по содержимому: короткие меню помещаются полностью, длинные прокручиваются при нехватке места. В выборе приложения — только название и иконка, поиск без учёта регистра, явное отсутствие результатов; выбор нескольких приложений сохраняется при смене поискового запроса.
- Ближайшие события календаря на главной и общий виджет на существующей странице **agenda**: текущие, будущие и события на весь день; завершённые, отменённые и скрытые события не показываются.
- Сетка месяца на **today** и главном экране: центрированные колонки дней недели и дат, выровненное выделение текущего дня; раскладка учитывает четыре, пять или шесть недель и размер текста.
- Погода Open-Meteo с резервным источником **wttr.in** при недоступности сервера прогноза; кириллический поиск города, уточнение страны, трёхдневный прогноз и локальный кэш.
- Реальные показатели батареи, памяти, хранилища и сетевого трафика; быстрые системные действия.
- Необязательный доступ к уведомлениям, календарю и управлению медиа.
- Задачи, заметки, калькулятор, Pomodoro с фоновыми сигналами, мировые часы и другие инструменты.
- **217 работ ascii.rest 0.4.0 внутри APK:** категории, поиск, оригинальные цвета или палитра лаунчера, пауза. Отдельная страница art и замена пейзажа на Zen. Интернет для арта не нужен.
- Живые обои для домашнего экрана / экрана блокировки через системный выбор Android. Погода использует общий город и кэш с главным экраном, подхватывает изменения и обновляется при возвращении к существующему локскрину; сохранённый прогноз доступен без сети.

## Установка и управление

1. Скачайте APK из [Releases](https://github.com/Arkuda/phosphor_demake/releases/latest) и разрешите установку из выбранного источника. Публикуемый APK — debug-сборка.
2. Откройте Phosphor → **◆ phosphor → set default launcher**, чтобы назначить его домашним экраном.
3. При необходимости включите доступ в **optional permissions** и настройте город в **weather / location**. Эти разрешения не обязательны для запуска лаунчера.

Язык интерфейса: **◆ phosphor → language → Русский**. Это первый пункт настроек; обратно — **язык → English**. По умолчанию сохраняется английский интерфейс. Перевод охватывает все 20 типов страниц, меню и диалоги, погоду, календарь, инструменты, подписи уведомлений таймера и интерфейс живых обоев. Названия, описания и категории всех 217 работ ascii.rest также переведены. Выбор сохраняется после перезапуска; уже работающий локскрин подхватывает его без замены движка обоев.

Имена установленных приложений, собственные подписи, заметки, события и содержимое чужих уведомлений не переводятся и не переписываются. Системные часы, клавиатура и системные окна разрешений остаются на языке Android. Примеры: [настройки на русском](captures/settings-ru-language-top.png), [арт](captures/art-ru.png), [настоящий локскрин RU](captures/keyguard-ru-language.png) и [EN](captures/keyguard-en-language.png).

Жесты: **вверх** — приложения, **вниз** — системная шторка, **влево / вправо** — страницы. Долгое нажатие на свободную область открывает редактирование страниц; на приложение — закрепление в нижнем баре, добавление/удаление из избранного, информацию и удаление приложения.

Переключение страниц: **◆ phosphor → page animation**. Выберите сжатие в CRT-строку, терминальный сдвиг, Matrix-развёртку или **off · instant** для мгновенного переключения. Выбор сохраняется после перезапуска; по умолчанию используется **CRT beam**. В энергосбережении эффекты короче; при выключенных системных анимациях переключение всегда мгновенное. Настройка не отключает фоновые CRT-эффекты и мигание часов.

Нижний бар: **◆ phosphor → dock apps** → позиция. Для занятой позиции доступны **choose app**, **rename label** и **empty slot**; пустая сразу открывает выбор приложения. Долгое нажатие на позицию открывает то же меню. **rename label → save** меняет только подпись в доке, сохраняя регистр; пустое поле возвращает стандартное имя. Общий список, избранное и запуск приложения не меняются. Если приложение уже есть в баре, позиции меняются местами, а собственная подпись следует за приложением. Удалённое приложение оставляет пустую позицию. **reset to defaults** восстанавливает начальный набор и стандартные подписи.

Избранное: **◆ phosphor → open favorites → [ edit ]** → отметьте приложения → **save**. **cancel** не применяет изменения; поиск не сбрасывает отметки. Чтобы страница постоянно была среди экранов, откройте **pages → add page → favorites**. Долгое нажатие на приложение в общем списке или избранном позволяет добавить/убрать его без изменения дока.

Рамки: **◆ phosphor → widget frames**. Настройка общая для главной, отдельных страниц и живых обоев; применяется к уже работающему локскрину. Заголовки, разделители, выделение текущей даты и элементы выбора остаются. **CRT glass** независимо управляет остальным CRT-эффектом.

События: разрешите чтение календаря в **optional permissions → calendar events** или прямо в виджете. **all ›** на главной и **◆ phosphor → calendar events** открывают существующий экран **agenda**; его также можно выбрать в редакторе страниц. Уведомления остаются на отдельной странице **inbox**.

Погода для Самары: **◆ phosphor → weather / location → choose city** → `Самара, РФ`, `Самара, RU` или `Samara, RU`. Геокодирование учитывает язык ввода и страну; используется часовой пояс выбранного города, для Самары — `Europe/Samara`. Название источника видно в виджете. Оставлены текущие условия и трёхдневный прогноз; температурный график убран вместе с неиспользуемыми почасовыми массивами и их запросом к Open-Meteo.

Принудительное обновление: нажмите **↻** справа в заголовке погодного виджета на главной или на странице **weather**. Кнопка не рисует чёрную подложку поверх леса. Во время запроса стрелка вращается, показывается `refreshing…` / `обновление…`, а последний прогноз остаётся виден. HTTP-кэш обходится; при ошибке сохраняется предыдущий прогноз и показывается статус ошибки. Если погода отключена, кнопка открывает её настройку.

Оформление погоды: **◆ phosphor → weather / location → ASCII weather**. Доступны **Landscape** (прежний точечный пейзаж), **Terminal icons** (крупный погодный символ), **ASCII postcard** (текстовый пейзаж с горами), **Orbital dial** (круговой ASCII-индикатор), **Forest lake** (прежний лес с озером) и **Forest lake true-ascii** (новые сгенерированные ASCII-сцены). В русском меню два последних пункта называются **«Лесное озеро»** и **«Лесное озеро true-ascii»**. Выбор сохраняется после перезапуска и применяется на главной, странице **weather** и в погодном режиме **Zen**; отдельный режим ascii.rest не меняется. Рисунки учитывают день/ночь, облачность, туман, морось, дождь, снег и грозу; без прогноза не добавляют выдуманные осадки или солнце/луну.

**Forest lake** — исходный процедурный рендер из тега **v1.6.0**: лес, горы, берега и отражения строятся нативным кодом из символов, без PNG-фона и без промежуточного FLA2-ресурса. В 1.7 вместо него по ошибке попал вариант на основе `weather-square-ref.png`; в **1.7.1** восстановлен именно опубликованный лес 1.6.0, с его прежними цветами, пропорциями и анимациями. Идентификатор `forest_lake` не изменён. Новый **true-ascii** использует отдельный `forest_lake_true_ascii`; автоматического переключения между ними нет.

Раздельный выбор доступен через настоящее меню Android: [Русский](captures/weather-styles-selector-ru.png), [English](captures/weather-styles-selector-en.png). После обновления 1.7 → 1.7.1 сохранены выбранный стиль, язык, палитра, страницы и заметка; проверено переключение между [исходным лесом 1.6.0](captures/hotfix-1.7.1-original-home.png) и [true-ascii](captures/hotfix-1.7.1-true-ascii-home.png). На снимках используются тестовые погодные данные.

**Forest lake true-ascii** использует десять отдельных цветных ASCII-референсов, сгенерированных GPT Image 2 с визуальным ориентиром [ascii.rest](https://ascii.rest/): снег, дождь, пасмурно, солнце и ночь, каждый в вариантах **16:9 (1536×864)** и **1:1 (1254×1254)**. Исходники лежат в `weather-references/gpt-image`; это рисунки из различимых печатных символов, а не пейзажи с пиксельным фильтром. Фоны намеренно не содержат падающих осадков и кругов от капель: эти эффекты рисуются отдельно в реальном времени.

Рендер выбирает вариант с наименьшей потерей площади при **cover** и равномерно масштабирует его до заполнения виджета. Края при необходимости обрезаются по центру; полей и растягивания деревьев/гор нет. Для квадратных и высоких областей используется квадратная композиция с дополнительным небом и водой, для широких — панорамная.

В **true-ascii** готовые символы и RGB сохраняются непосредственно в PNG: повторного квантования в ASCII, второй крупной сетки глифов, нормализации яркости и цветной тональной подложки нет. При уменьшении один раз усредняется площадь исходных пикселей, при увеличении интерполируется RGB. ARGB8888-кэш ограничен 2048 px на ось и сохраняется между кадрами; по ширине он содержит только видимую часть сцены с запасом для рефракции. Цвета не зависят от темы лаунчера. Отдельного CRT, bloom или размытия внутри true-ascii нет; общий переключатель CRT остаётся независимым.

Мелкие анимированные знаки рисуются нативным моноширинным шрифтом сразу в конечном размере: уменьшение старого bitmap-атласа могло полностью пропустить тонкий штрих точки или тире. Позиции солнечных бликов заранее выбираются по настоящим золотистым штрихам отражения внутри маски воды, а не по случайным чёрным промежуткам между символами. Координаты солнца/луны и отдельные консервативные полигоны озера хранятся в `geometry.json` рядом с референсами.

Вода колышется за счёт смещения отражений и движущихся бликов. После попадания дождевой капли появляются всплеск и **три расходящихся затухающих эллиптических волны**; несколько локальных полос рефракции дают видимые разводы отражения вокруг удара. Конец падающей капли совпадает с центром колец. В морось плотность, размер и яркость эффекта меньше. Маска открытого озера проверяет весь след линий, фильтрации и сглаживания: берег и камни не двигаются. Снежинки падают тремя слоями; солнечные блики используют положение солнца из нового референса. Анимация использует существующий цикл отрисовки и его энергосберегающую частоту.

Визуальные ориентиры первых наборов: [wego](https://github.com/schachmat/wego/blob/master/frontends/ascii-art-table.go) и [wttr.in](https://github.com/chubin/wttr.in#usage); Forest lake true-ascii — отдельный сгенерированный набор. Его графика проверена на Android с явно обозначенными тестовыми погодными условиями: [оба формата пяти сцен](captures/weather-gpt-ascii-scenes.png), [дождь и разводы — GIF](captures/weather-gpt-ascii-rain.gif), [главная](captures/weather-gpt-ascii-home.png), [погода с дождём](captures/weather-gpt-ascii-page.png), [пять настоящих страниц погоды](captures/weather-gpt-ascii-pages.png), [солнце](captures/weather-gpt-ascii-sun-page.png), [Zen](captures/weather-gpt-ascii-zen.png), [paper / XL](captures/weather-gpt-ascii-paper-xl.png), [главная 1080×2340](captures/weather-gpt-ascii-1080-home.png), [погода 1080×2340](captures/weather-gpt-ascii-1080-page.png). Это не снимки живого прогноза. Промежуточные сцены на основе квадратного коллажа больше не используются; их примеры сохранены только в истории изменений.

Погоду для локскрина отдельно настраивать не нужно: он использует тот же прогноз. При загрузке, отключённой погоде или ошибке показывается соответствующее состояние, а не ложное «weather not configured».

Арт: **◆ phosphor → ASCII art**. Выберите **browse catalogue**, **open art page** или переключите **Zen scene**. Страницу art также можно добавить через редактор страниц.

Для композиции экрана блокировки выберите компактные системные часы в настройках Android. Приложение не может перемещать или заменять часы, нарисованные самой системой; большие двухстрочные часы могут перекрывать живые обои.

## Требования и сборка

- Android **8.0 / API 26+**; для арта — актуальный Android System WebView.
- Для сборки: **JDK 17**, Android SDK Platform **35**. Укажите SDK через `ANDROID_HOME` или локальный `local.properties` с `sdk.dir`.

Windows:

```powershell
.\gradlew.bat :app:assembleDebug
```

Linux / macOS:

```sh
./gradlew :app:assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.

Самостоятельная debug-сборка использует локальный ключ. Для публикации обновления нужен ключ прежнего APK: сравните SHA-256 сертификатов через `apksigner verify --print-certs`. Расположение ключа зависит от `ANDROID_USER_HOME`; смена этого каталога может незаметно сменить подпись.

Готовые арт-ресурсы уже включены в исходники: Node.js и Python для обычной Android-сборки не требуются. Для повторной генерации отдельного каталога **ascii.rest** нужен Node.js **22.18+**:

```sh
npm ci --ignore-scripts
npm run build:ascii
```

PNG-ресурсы **true-ascii** пересоздаются отдельно (Python 3 и Pillow). Обычный лес генерируется процедурно в Android и внешнего конвертера не требует:

```sh
python -m pip install Pillow
python scripts/build-weather-ascii.py weather-references/gpt-image --cell 1
```

У PNG-конвертера `build-weather-ascii.py` дополнительные параметры: `--contrast` (−255…255, по умолчанию 0), `--brightness` (−100…100 %, по умолчанию 0), `--output` (каталог результата). По умолчанию каждый RGB-пиксель сохраняется без изменений. `--cell 2` уменьшает оба формата BOX-фильтром с сохранением полного изображения и точных пропорций; слишком большой коэффициент, при котором точные пропорции невозможны, отклоняется до записи. Конвертер проверяет все десять входных PNG и `geometry.json`, затем создаёт `app/src/main/assets/weather/forest-lake.json` и PNG в подкаталогах `wide`/`square`. Неиспользуемые FLA2-ресурс и его конвертер удалены. Обычная Android-сборка не запускает Python и не обращается к генератору или сайту.

## Приватность и авторство

Нет аккаунтов, рекламы и аналитики. Приложения, заметки, задачи, календарь и уведомления обрабатываются локально. Только настроенная погода отправляет название города в геокодирование Open-Meteo и координаты в его API прогноза; при недоступности сервера прогноза координаты отправляются в [wttr.in](https://github.com/chubin/wttr.in#json-output). Координаты местоположения устройства округляются до двух знаков. Арт работает с локальными ресурсами, без загрузки сайта или CDN.

Это независимая реализация, не оригинальное приложение Phosphor и не проект его автора. Пиксель-в-пиксель соответствие закрытому оригиналу не заявляется.

Работы и рендерер **ascii.rest** созданы [@bas3line](https://github.com/bas3line) и распространяются по MIT. Исходный текст лицензии сохранён в [app/src/main/assets/ascii/LICENSE](app/src/main/assets/ascii/LICENSE) и доступен в приложении через **ASCII art → MIT license**.
